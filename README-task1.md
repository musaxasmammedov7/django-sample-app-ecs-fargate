# Task 1: Deploy and Configure Infrastructure Using Terraform and Ansible

## Overview

Infrastructure as Code for the Healthchecks Django application using Terraform (AWS) and Ansible (configuration management via SSM).

## Architecture

```
Internet → ALB (public) → nginx (app-01/02, private) → gunicorn → Django → PostgreSQL (db-01, private)
                              ↑                                    ↑
                         port 80                              port 5432
```

- **VPC**: 10.0.0.0/16 with public (2 AZ) and private (2 AZ) subnets
- **ALB**: Public load balancer distributing traffic to app instances
- **EC2**: 2 app instances + 1 database instance (all in private subnets)
- **SSM**: Manage instances without SSH (SMP agent preinstalled)
- **Ansible**: Configuration management via SSM connection

## Structure

```
├── terraform/
│   ├── providers.tf        # AWS provider, region eu-north-1
│   ├── variables.tf        # All configurable variables
│   ├── vpc.tf              # VPC, subnets, IGW, NAT, route tables, security groups
│   ├── iam.tf              # IAM role for EC2 (SSM access)
│   ├── ec2.tf              # 3 instances: app-01, app-02, db-01
│   ├── alb.tf              # ALB, target group, listener
│   ├── ssm.tf              # SSM operator policy for Ansible
│   └── outputs.tf          # Inventory file generation
├── ansible/
│   ├── db.yml              # Playbook for database setup
│   ├── webservers.yml      # Playbook for web server setup
│   ├── deploy.yml          # Playbook for application deployment
│   ├── inventory.ini       # Generated by Terraform (auto-created)
│   └── roles/
│       ├── postgres-setup  # Install PostgreSQL, create user + DB
│       ├── webserver-setup # Install Python + Nginx
│       └── deploy          # Clone code, configure env, migrate, start gunicorn
└── README.md
```

## Deployment

### 1. Initialize and apply Terraform

```bash
cd terraform
terraform init
terraform apply
```

This creates:
- VPC with subnets across 2 AZs
- 3 EC2 instances (2 app + 1 db) in private subnets
- ALB in public subnets
- `inventory.ini` file for Ansible

### 2. Run Ansible playbooks

```bash
cd ansible

# Install and configure PostgreSQL
ansible-playbook -i inventory.ini db.yml

# Install Python and Nginx
ansible-playbook -i inventory.ini webservers.yml

# Deploy the application
ansible-playbook -i inventory.ini deploy.yml
```

### 3. Access the application

```bash
# Get ALB DNS from Terraform output
terraform -chdir=terraform output alb_dns_name

# Open in browser
open http://$(terraform -chdir=terraform output -raw alb_dns_name)
```

## Security

- All instances are in **private subnets** (no public IP)
- Access via **SSM** (no SSH keys needed)
- Security groups restrict traffic:
  - ALB: port 80 from internet only
  - App: port 80 from ALB only
  - DB: port 5432 from App only

## Variables

Edit `terraform/variables.tf` to customize:

| Variable | Default | Description |
|---|---|---|
| aws_region | eu-north-1 | AWS region |
| instance_type | t3.micro | EC2 instance type |
| db_name | hc | PostgreSQL database name |
| db_user | hc_user | PostgreSQL username |
| db_password | (stored in Ansible Vault) | PostgreSQL password |
| github_repo | musaxasmammedov7/django-sample-app.git | App repository |
